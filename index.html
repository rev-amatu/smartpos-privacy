Kebijakan Privasi SmartPos

Terakhir diperbarui: 31 Mei 2026

Data yang Dikumpulkan

SmartPos menyimpan semua data (produk, transaksi, pengaturan) secara lokal di perangkat Anda. Data tidak dikirim ke server kami.

Layanan Pihak Ketiga

  • Google AdMob — menampilkan iklan untuk pengguna gratis.
  • RevenueCat — memproses pembelian dalam aplikasi (premium).

Izin Aplikasi

  • Kamera — untuk pemindaian barcode produk
  • Bluetooth — untuk cetak struk via printer Bluetooth
  • Internet — untuk verifikasi premium dan iklan

Keamanan Data

Data transaksi dan bisnis Anda tersimpan hanya di perangkat Anda. Anda dapat melakukan backup dan restore data kapan saja.
